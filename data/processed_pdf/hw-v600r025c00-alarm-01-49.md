可能原因
● 原因1：A link fault occurred or negotiation information synchronization failed.（链路故障或协商信息未同步。）
● 原因2：The remote system MAC address in the received LACPDU was the same as the local system MAC address.（收到的远端LACP报文中携带的系统MAC和本地的系统MAC相同。）
处理步骤
● 原因1：A link fault occurred or negotiation information synchronization failed.
请在接口视图下执行命令display this，查看两端接口是否被shutdown。
1.
– 如果接口被 shutdown ，可执行命令 undo shutdown 打开接口，然后检查告警是否被清除。如果未被清除，则请执行步骤2。
– 如果接口未被shutdown，则请执行步骤2。
2. 请查看物理链接是否正常（包括网线、光模块等硬件是否松动或脱落）。
– 如果物理链路工作不正常，可以重新正确连接物理线路，然后检查告警是否被清除。如果未被清除，则请执行步骤3。
– 如果物理链路工作正常，则请执行步骤3。
3. 请在系统视图下执行命令display interface eth-trunk，查看本端和对端是否有端口退出Eth-Trunk。
– 如果端口是非正常退出Eth-Trunk，可通过在成员接口视图下执行命令eth- trunk或在Eth-Trunk接口视图下执行命令trunkport将接口重新加入Eth- Trunk，然后检查告警是否被清除。如果未被清除，则请执行步骤4。
– 如果端口是正常退出Eth-Trunk，则请执行步骤4。
4. 请收集告警信息、日志信息和配置信息，并联系技术支持人员。
● 原因2：The remote system MAC address in the received LACPDU was the same as the local system MAC address.
1. 检查是否是环回口。
– 如果是环回口，则请执行步骤2。
– 如果不是环回口，请执行步骤3。
2. 清除环回配置，查看告警是否恢复。
– 如果清除环回配置告警恢复，则请执行步骤4。
– 如果清除环回配置告警不恢复，则请执行步骤3。
3. 请收集告警信息、日志信息和配置信息，并联系华为技术支持工程师。
4. 结束。

● 如果是，则请执行步骤6。
● 如果不是，则请执行步骤9。
6. 在 Eth-Trunk 接口视图下，执行命令 least active-linknumber <link-number> ，正确配置Trunk口成员链路Up的下限阈值，查看告警是否恢复。
● 如果是，则请执行步骤10。

● 如果不是，则请执行步骤9。
7. 正确修复物理链路，查看告警是否恢复。
● 如果是，则请执行步骤10。
● 如果不是，则请执行步骤4。
8. 在接口视图下执行命令eth-trunk <trunk-id>，根据实际需要将当前以太网接口加入
Eth-Trunk组，查看告警是否恢复。
● 如果是，则请执行步骤10。
● 如果不是，则请执行步骤5。
9. 请收集告警信息和配置信息，并联系技术支持工程师。

● 原因3：LACP is disabled on the current interface.
无影响。
● 原因4：The function to forcibly set the LACP status to up takes effect.
此链路可以承载业务。
● 原因5：LACP negotiation succeeds.
此链路可以承载业务。
● 原因6：LACP force up failed due to remote trunk interface changed to protocol up.
此链路不能承载业务。
可能原因
● 原因3：LACP is disabled on the current interface.（LACP在当前接口上去使能。）
● 原因4：The function to forcibly set the LACP status to up takes effect.（LACP强制 UP 功能生效。）
● 原因5：LACP negotiation succeeds.（LACP协商成功。）
● 原因6：LACP force up failed due to remote trunk interface changed to protocol up.（LACP由于远端Trunk接口协议UP导致强制UP失效。）
处理步骤正常运行信息，无需处理。
