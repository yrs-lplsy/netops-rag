可能原因
● 原因1：The bandwidth of the slice interface is insufficient, and the rate limiting function does not take effect. （切片接口的带宽不足，限速功能不生效。）

处理步骤
● 原因1：The bandwidth of the slice interface is insufficient, and the rate limiting function does not take effect.
1.执行display network-slice usage statistics interface <interface-name>查看接口的带宽使用情况，查看是否有不需要的带宽分配。
– 如果配置都是需要的，执行步骤3；
– 如果配置有不需要的，执行步骤2；
2.执行undo network-slice <slice-id> flex-channel <flex-channel-value> 命令删除不需要的网络切片，或者执行network-slice <slice-id> flex-channel <flex- channel-value> 命令修改配置的带宽大小。
3.请收集告警信息、日志信息和配置信息，联系技术工程师。
● 原因2：The network slice resources are insufficient, and the rate limiting function does not take effect.
1.执行display network-slice usage statistics interface <interface-name>查看接口的网络切片资源使用情况，是否有不需要的切片分配。
– 如果配置都是需要的，执行步骤3；
– 如果配置有不需要的，执行步骤2；
2. 执行 undo network-slice <slice-id> flex-channel <flex-channel-value> 命令删除不需要的网络切片。
3.请收集告警信息、日志信息和配置信息，联系技术工程师。

● 原因3：The number of network slices exceeds the limit, and the rate limiting
function does not take effect.
1.执行display current-configuration查看网络切片配置信息，是否有不需要的带
宽分配。
– 如果配置都是需要的，执行步骤3；
– 如果配置有不需要的，执行步骤2；
2.执行undo network-slice <slice-id> flex-channel <flex-channel-value> 命令删
除不需要的网络切片。
3.请收集告警信息、日志信息和配置信息，联系技术工程师。
