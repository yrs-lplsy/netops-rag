### 104.2 WEB_1.3.6.1.4.1.2011.5.4.2.2.1.2 hwPortalServerDown

Trap Buffer 信息解释The portal server is down. (IP=[IpAddr], VpnInstance=[VpnInstance])
开启服务器探测功能并设置告警动作后，设备探测到Portal服务器状态由UP转变为DOWN。

Trap 属性

| Trap属性 | 描述 |
|---|---|

| Trap Severity | Warning |

| Alarm ID | 0x0AEC2002/0xAEC2002 |
| Alarm Severity | Warning |
| Alarm Name | hwPortalServerDown |
| Alarm Type | communicationsAlarm |
| Raise or Clear | Raise |
| Match trap | WEB_1.3.6.1.4.1.2011.5.4.2.2.1.1 hwPortalServerUp |

Trap Buffer 信息参数

| 参数名称 | 参数含义 |
|---|---|
| IpAddr | Portal服务器IP地址 |
| VpnInstance | Portal服务器VPN实例 |

VB 信息参数

| VB OID | VB Name | VB Index |
|---|---|---|
| 1.3.6.1.4.1.2011.5.4.2.1.1 | hwStateChangePortalSer verIp | - |
| 1.3.6.1.4.1.2011.5.4.2.1.2 | hwStateChangePortalSer verVrf | - |

对系统的影响Portal认证功能无法正常使用。
可能原因Portal服务器状态由UP转变为DOWN。

处理步骤
1.执行命令display portal-server state检查部署的Portal服务器是否工作正常，能否正常使用Portal服务。
•如果Portal服务器正常，请检查Portal服务器与设备的网络连接状况。若网络断开，请恢复。
•如果Portal服务器不正常，请尽快恢复Portal服务器到正常工作状态。
2.请收集日志和配置信息，联系技术支持人员。
