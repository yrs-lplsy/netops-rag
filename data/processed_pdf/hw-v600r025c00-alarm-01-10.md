### 10.1 CFG_1.3.6.1.4.1.2011.6.10.2.23 hwCfgMinisystemConfigRecovery

10.1 CFG_1.3.6.1.4.1.2011.6.10.2.23
hwCfgMinisystemConfigRecovery
Trap Buffer 信息解释
The system use mini-system configurations to recovery.
系统使用最小系统配置恢复。
Trap 属性

| Trap属性 | 描述 |
|---|---|
| Alarm or Event | Alarm |
| Trap Severity | Critical |
| Trap OID | 1.3.6.1.4.1.2011.6.10.2.23 |
| MIB | HUAWEI-CONFIG-MAN-MIB |
| Alarm ID | 0x00F1053C/0xF1053C |
| Alarm Severity | Major |
| Alarm Name | MINISYSTEM_CONFIG_RECOVERY |
| Alarm Type | equipmentAlarm |
| Raise or Clear | Raise |
| Match trap | CFG_1.3.6.1.4.1.2011.6.10.2.24 hwCfgMinisystemConfigRecoveryClear |

Trap Buffer 信息参数无VB 信息参数无对系统的影响设备以最小系统配置恢复。
可能原因设备以最小系统配置恢复。
处理步骤确认设备故障排除后，从最小系统中恢复到正常系统，设备起来可以通过命令display startup 查看当前恢复的文件是否是 mini-system ，如果是说明当前设备就是以最小系统配置恢复。
1.当用户希望以最小系统启动时，为正常运行信息，无需处理。
2.当用户不希望以最小系统启动时，则不要在系统视图下使用startup saved- configuration mini-system尝试以最小系统启动，并且还可以尝试在诊断视图下通过reset saved-configuration mini-system清除设备上配置了的mini-system配置文件。
