对系统的影响PIM 邻居连接中断或连接建立失败，路由不可达，数据转发业务中断。
可能原因
● 原因1：Neighbor timer expired.（邻居的HoldTime定时器超时。）
● 原因3：Interface is down.（邻居所在接口Down。）
● 原因5：Neighbor is deleted.（邻居删除。）
● 原因7：Receive hello cancel message.（收到HoldTime为零的邻居消息。）
● 原因8：BFD session is down.（邻居的BFD会话down。）

处理步骤
● 原因1：Neighbor timer expired.
1. 使用命令ping或ping ipv6检查和邻居之间的链路是否连通。
– 如果连通，则请执行步骤3。
– 如果不连通，则请执行步骤2。
2. 使用命令display ip routing-table或display ipv6 routing-table命令检查到邻居的单播路由是否正常。
– 如果路由正常，则请执行步骤3。
– 如果路由不正常，则排除单播路由故障来解决告警问题。
3. 在对应邻居接口视图下使用display this命令查看接口是否使能了PIM-SM。
– 如果使能了PIM-SM，则说明对应邻居接口更改了IP地址，旧IP地址的邻居丢失，等待一段时间若邻居未重新建立，请执行步骤4。
– 如果没有使能，则请在接口下使能PIM-SM。
4. 请收集告警信息和配置信息，并联系技术支持工程师。
● 原因3：Interface is down.
1. 在设备上使用命令display interface brief或display ipv6 interface brief查看接口的状态，检查协议层状态是否为Up。
– 如果协议层状态是Up，则请执行步骤2。
– 如果协议层状态是Down，可执行ip address或ipv6 address命令为接口配置IP地址。
– 如果接口状态是Down，可执行undo shutdown命令。
2. 请收集告警信息和配置信息，并联系技术支持工程师。
● 原因5：Neighbor is deleted.
1. 使用命令ping或ping ipv6检查和邻居之间的链路是否连通。
– 如果连通，则请执行步骤2。
– 如果不连通，则请检查接口状态。
2. 使用命令display ip routing-table或display ipv6 routing-table命令检查到邻居的单播路由是否正常。
– 如果路由正常，则请执行步骤3。
– 如果路由不正常，则排除单播路由故障来解决告警问题。
3. 在对应的接口视图下执行display this命令查看接口是否配置了pim neighbor- policy或pim ipv6 neighbor-policy。
– 如果配置了，则请执行步骤4。
– 如果没有配置，则请执行步骤5。
4. 执行 display acl 或 display acl ipv6 命令查看 ACL 配置是否符合要求。
– 如果符合要求，则请执行步骤5。
– 如果不符合要求，则重新配置ACL规则。

5. 在对应的接口视图下执行display this命令查看接口是否配置了pim silent或pim
ipv6 silent。
如果配置了，则请删除pim silent或pim silent配置。
– ipv6
– 如果没有配置，则请执行步骤6。
6. 请收集告警信息和配置信息，并联系技术支持工程师。
● 原因7：Receive hello cancel message.
1. 在邻居设备对应的接口视图下用display this 命令查看接口是否使能了pim sm
或pim ipv6 sm.
– 如果使能了pim sm或pim ipv6 sm，则请执行步骤2。
– 如果没有使能，则请在接口上配置pim sm或pim ipv6 sm使能。
2. 在设备上检查接口状态，用display ip interface brief或display ipv6 interface
brief命令查看对应的接口状态是否是UP状态。该接口是否配有IP地址。
– 如果协议层状态是Up，则请执行步骤3。
– 如果协议层状态是Down，可执行ip address或ipv6 address命令为接口配置IP
地址。
– 如果接口状态是Down，可执行undo shutdown命令。
3. 请收集告警信息和配置信息，并联系技术支持工程师。
● 原因8：BFD session is down.
1.在邻居设备对应的接口视图下用display this 命令查看接口是否使能了pim sm或
pim ipv6 sm.
– 如果使能了pim sm或pim ipv6 sm，则请执行步骤2。
– 如果没有使能，则请在接口上配置pim sm或pim ipv6 sm使能。
2.在设备上检查接口状态，用display ip interface brief或display ipv6 interface
brief命令查看对应的接口状态是否是UP状态。
– 如果协议层状态是Up，则请执行步骤3。
– 如果协议层状态是Down，可执行ip address或ipv6 address命令为接口配置IP
地址。
– 如果接口状态是Down，可执行undo shutdown命令。
3.检查到对端设备的路由是否正常。用display ip routing-table或display ipv6
routing-table 查看。
– 如果路由正常，则请执行步骤4。
– 如果路由不正常，配置到对端设备的路由。
4.请收集告警信息和配置信息，并联系技术支持工程师。
