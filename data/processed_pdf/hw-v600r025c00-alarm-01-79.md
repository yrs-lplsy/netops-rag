| 1.3.6.1.4.1.2011.5.25.667. 1.3 | hwRuMngRuLinkExceptio nReason | - |

对系统的影响中心设备和远端模块之间流量转发可能会异常。

可能原因
● 原因1：The port connected to the remote unit is not added to the same Eth- Trunk（中心设备的接口未加入到同一个Eth-Trunk。）
● 原因2：The timeout of receiving XLDPPDU（接收XLDP报文超时。）
● 原因3：The port link of the remote unit is faulty（远端模块端口链路故障。）
● 原因4：The ports of the remote unit are connected to different devices（远端模块接入到多个设备。）
● 原因5：XLDP is not enabled on the other interface connected to the RU.（与远端模块相连的另一个接口没有使能XLDP。）
处理步骤
● 原因1：The port connected to the remote unit is not added to the same Eth- Trunk执行命令行display this interface，检查中心设备的互联口是否加入同一个Eth- Trunk。若不是，可以执行命令trunkport interface-type { interface-number1 [ to interface-number2 ] } &<1-16> [ mode { active | passive } ] ，将两个端口加入同一个Eth-trunk。
● 原因2：The timeout of receiving XLDPPDU执行命令行display xldp statistics，查看中心设备互联口的XLDP的收发计数。回显中Transmitted frames total表示发送的XLDP报文数，Received frames total表示接收的XLDP报文数。如果计数未变化，说明未处理XLDP报文，请检查链路状态。
● 原因3：The port link of the remote unit is faulty在中心设备互联口视图下执行命令行display this interface查看端口是否up，如果状态为DOWN,检查连线或二端的光模块参数是否一致。
● 原因4：The ports of the remote unit are connected to different devices请检查远端模块与中心设备的连线，是否同一个远端模块上行端口连接到不同的中心设备。
● 原因5：XLDP is not enabled on the other interface connected to the RU.
在中心设备互联口视图下执行命令行display this检查XLDP是否使能。若不是，可以执行命令xldp enable命令使能xldp。

● 如果是，则请排除邻居和本端设备之间的链路故障。
● 如果不是，则请执行3。
3. 请收集日志信息和配置信息，并联系技术支持工程师。
原因3：因老化时间超时导致邻居被老化。
1. 执行display lldp statistics命令，查看本端设备上保存的邻居节点信息是否超时。
● 如果是，则该日志信息属于正常运行信息，无需处理。
● 如果不是，则请执行2。
2. 查看邻居与本端设备直连的端口是否被shutdown。
● 如果是，则请在该直连端口上执行undo shutdown命令，将该端口的状态置为Up。
● 如果不是，则请执行3。
3. 请收集日志信息和配置信息，并联系技术支持工程师。
