对系统的影响
● 原因1：The block memory usage exceeded the threshold
1.可能会影响该单板上的转发、用户接入、kpi等业务，甚至业务中断。
2.如果持续劣化，可能由于block内存耗尽触发单板复位。
● 原因2：The usage of client asynchronous messages exceeded the threshold
1.可能会影响该单板上的转发、用户接入等业务，甚至业务中断。
2.如果持续劣化，可能由于客户端异步消息耗尽触发单板复位。
● 原因3：The usage of subscription messages exceeded the threshold
1.可能会影响该单板上的转发、用户接入、kpi等业务，甚至业务中断。
2.如果持续劣化，可能由于订阅消息耗尽触发单板复位。
● 原因4：The usage of client connections exceeded the threshold
1.可能会影响该单板上的转发、用户接入、kpi等业务，甚至业务中断。
2. 如果持续劣化，可能由于客户端连接耗尽触发单板复位。
● 原因5：The usage of client objects exceeded the threshold
1.可能会影响该单板上的转发、用户接入等业务，甚至业务中断。
2.如果持续劣化，可能由于客户端对象耗尽触发单板复位。
● 原因6：The memory usage of the server tablespace exceeds the threshold
1.可能会影响该单板上的转发、用户接入、kpi等业务，甚至业务中断。
2.如果持续劣化，可能由于服务端表空间内存耗尽触发单板复位。
● 原因7：The memory usage of subscription messages exceeded the threshold
1.可能会影响该单板上的转发、用户接入、kpi等业务，甚至业务中断。
2.如果持续劣化，可能由于订阅消息的内存耗尽触发单板复位。
● 原因8：The heap memory usage exceeded the threshold
1.可能会影响该单板上的转发、用户接入、kpi等业务，甚至业务中断。
2.如果持续劣化，可能由于堆内存耗尽触发单板复位。
● 原因32：The usage of client asynchronous messages in the YANG DB exceeded the threshold
1.可能会影响该单板上的转发、用户接入、kpi等业务，甚至业务中断。
2.如果持续劣化，可能由于YANG DB的客户端异步消息耗尽触发单板复位。
● 原因34：The usage of client connections in the YANG DB exceeded the threshold
1.可能会影响该单板上的转发、用户接入、kpi等业务，甚至业务中断。
2.如果持续劣化，可能由于YANG DB的客户端连接耗尽触发单板复位。
● 原因 36 ： The memory usage of the server tablespace in the YANG DB exceeds the threshold
1.可能会影响该单板上的转发、用户接入等业务，甚至业务中断。

2.如果持续劣化，可能由于YANG DB的服务端表空间内存耗尽触发单板复位。
