| VB OID | VB Name | VB Index |
|---|---|---|
| 1.3.6.1.4.1.2011.5.25.207. 1.5.5 | hwCurrentVty | - |
| 1.3.6.1.4.1.2011.5.25.207. 1.5.6 | hwMaxVty | - |

对系统的影响VTY通道被占用完后，用户无法登录系统。
可能原因系统上可用的VTY通道数低于阈值（阈值可以通过user-interface vty available-vty- threshold命令修改）。如：设备通过命令行user-interface vty配置了5个VTY通道，且设置可用的VTY通道的阈值为4。当可用的VTY通道数小于4时产生告警；当可用的VTY通道数大于等于4时告警清除。告警没有消除前，每次可用VTY通道个数变化都会刷新一次告警，告知当前最新的VTY使用情况。
处理步骤
1. 增加可用VTY通道数，使其大于阈值：执行命令user-interface maximum-vty <number>增加系统VTY通道数的最大值，并且在执行命令user-interface vty first-ui- number [ last-ui-number ]时增大first-ui-number与last-ui-number参数间的差值，同时在新增加的VTY用户界面视图下配置认证模式。
● 如果告警消除，请执行步骤 5 。
● 如果告警未消除，请执行步骤2。
2. 增加可用VTY通道数，使其大于阈值：将已登录用户退出。
● 如果告警消除，请执行步骤5。
● 如果告警未消除，请执行步骤3。
3. 降低超限告警阈值：执行user-interface vty available-vty-threshold命令降低可用VTY通道数的超限告警阈值。
● 如果告警消除，请执行步骤 5 。
● 如果告警未消除，请执行步骤4。
4. 请收集日志信息和配置信息，并联系技术支持工程师。

5. 结束。
