### 16.1 DHCP_1.3.6.1.4.1.2011.5.7.1.3.1 hwPDRouteExceed

Trap Buffer 信息解释The number of PD route for DHCPv6 relay reached the maximum.
DHCPv6中继PD路由达到最大值告警。
Trap 属性

| Trap属性 | 描述 |
|---|---|
| Alarm or Event | Alarm |
| Trap Severity | Warning |
| Trap OID | 1.3.6.1.4.1.2011.5.7.1.3.1 |
| MIB | HUAWEI-DHCPR-MIB |
| Alarm ID | 0x0DBC2116/0xDBC2116 |
| Alarm Severity | Warning |
| Alarm Name | hwPDRouteExceed |
| Alarm Type | qualityOfServiceAlarm |
| Raise or Clear | Raise |
| Match trap | DHCP_1.3.6.1.4.1.2011.5.7.1.3.2 hwPDRouteExceedResume |

Trap Buffer 信息参数无VB 信息参数无

对系统的影响客户端获取PD前缀，但业务数据转发失败。
可能原因DHCPV6中继的PD路由表规格有限制， 当上线的DHCPv6 PD客户端过多时，DHCPv6 PD客户端添加到DHCPv6中继上的PD路由表可能会超规格，导致DHCPv6中继不再生成PD路由表。DHCPv6中继上没有对应的PD路由表，进一步导致客户端业务数据转发失败。
处理步骤减少DHCPv6 PD客户端的数量，使DHCPv6中继上的PD路由表不超过规格。
