### 83.3 SNMP_1.3.6.1.6.3.1.1.5.5 authenticationFailure

Trap Buffer 信息解释Failed to login through SNMP. (IPAddressType=[IPAddressType], IPAddress=[IPAddress], ReasonInfo=[ReasonInfo])
Trap 属性

| Trap属性 | 描述 |
|---|---|
| Alarm or Event | Event |
| Trap Severity | Warning |
| Trap OID | 1.3.6.1.6.3.1.1.5.5 |

| Trap属性 | 描述 |
|---|---|
| MIB | SNMPv2-MIB |
| Alarm ID | 该Trap是事件Trap，不涉及告警ID。 |
| Alarm Severity | 该Trap是事件Trap，不涉及告警级别。 |
| Alarm Name | 该Trap是事件Trap，不涉及告警名称。 |
| Alarm Type | 该Trap是事件Trap，不涉及告警类型。 |
| Raise or Clear | 该Trap是事件Trap，不涉及告警产生或恢复。 |
| Match trap | - |

Trap Buffer 信息参数

| 参数名称 | 参数含义 |
|---|---|
| IPAddressType | IP类型。 ● 1：代表IPv4 ● 2：代表IPv6。 |
| IPAddress | 网管的IP地址。 |
| ReasonInfo | 错误产生原因的描述。 |

VB 信息参数无对系统的影响用错误的团体名称或SNMPv3用户名连接设备，对业务没有影响。
可能原因原因1：团体名或用户名错误。
原因2：认证密码或加密密码错误。
处理步骤
1.SNMPv1和SNMPv2c：如果SNMP Agent配置了团体名，请使用正确的团体名登录。
2.SNMPv3：如果SNMP Agent配置了USM用户，请使用正确的用户名和密码登录。
