## 23 二层流量限制配置

### 23.1 二层流量限制简介

为了保证单播流量的发送，可以对未知单播、未知组播流量允许转发的带宽大小分别进行限制。
23.2 二层流量限制配置注意事项
23.3 配置基于BD的二层流量限制禁止端口向BD内的其他端口广播报文可预防设备受到恶意攻击，从而提高网络的安全性。
23.4 配置基于VLAN的二层流量限制基于VLAN的流量进行限制，防止过多的报文流量对网络造成负担。
23.1 二层流量限制简介为了保证单播流量的发送，可以对未知单播、未知组播流量允许转发的带宽大小分别进行限制。
定义二层网络中的流量分为以下几种：
● 单播流量：目的 MAC 已经存在于 MAC 表中的单播流量，设备根据 MAC 表中的信息对这种报文进行单播发送。
未知单播流量：目的MAC不在MAC表中的单播流量，设备对此种流量进行广播发
●送。
● 组播流量：目的MAC为组播的流量，设备对此种流量一般进行广播发送。
● 未知组播流量：设备打开二层组播后，目的MAC或IP为组播的流量，查组播转发表不命中的流量，设备对此种流量一般进行广播发送。
目的为了保证单播流量的发送，设备可以对未知单播、未知组播允许转发的带宽大小分别进行限制。

### 23.3 配置基于BD的二层流量限制

禁止端口向BD内的其他端口广播报文可预防设备受到恶意攻击，从而提高网络的安全性。

背景信息当BD中的一个EVC二层子接口收到未知组播报文时，将向BD内的其他接口广播该报文。
如果是未知组播报文，将会占用设备资源，导致设备性能下降甚至瘫痪。通过配置禁止接口向BD内的其他接口广播接收到的报文，可预防设备受到恶意攻击。
适用于网络环境固定的场景或已经配置了静态MAC地址明确转发路径的场景。
说明该配置仅S6780-H、S6750-H、S6730-S-V2、S6750-S、S6750E-S、S6730-H-V2、S6730E-H- V2、S5755-H、S5755-S、S5732-H-V2系列支持。
操作步骤步骤1 进入系统视图。
system-view步骤 2 进入 BD 视图。
bridge-domain bd-id步骤3 配置禁止端口向BD内的其他端口转发未知组播报文。
unknown-multicast discard
----结束

### 23.4 配置基于VLAN的二层流量限制

基于VLAN的流量进行限制，防止过多的报文流量对网络造成负担。
背景信息进行流量限制的接口必须是二层接口。
操作步骤步骤1 进入系统视图。
system-view步骤2 进入接口视图。
interface interface-type interface-number步骤3 配置接口从三层模式切换到二层模式。
portswitch仅S6780-H系列、S6750-H系列、S6730-H-V2系列、S6730E-H-V2系列、S6750-S系列、S6730-S-V2系列、S6750E-S系列、S5732-H-V2系列、S5755-H系列、S5755-S系列支持该步骤。请用户根据实际接口类型自行选择是否要执行此步骤。
步骤4 返回到系统视图。
quit步骤5 创建指定VLAN。
vlan batch { vlan-id1 [ to vlan-id2 ] } &<1-10>

步骤6 将接口加入到VLAN。
port interface-type { interface-number1 [ to interface-number2 ] } &<1-10>步骤7 配置VLAN下端口禁止转发未知组播报文。
unknown-multicast discard缺省情况下，VLAN下端口转发未知组播报文。
----结束
