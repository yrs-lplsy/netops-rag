98.1 VCMP_1.3.6.1.4.1.2011.5.25.42.3.1.4.2
hwVcmpServerMacConflict
Trap Buffer 信息解释
More than one server exists in the VCMP domain.
(VcmpDeviceMac=[VcmpDeviceMac])
同一个VCMP管理域中出现多个角色为Server的设备。
Trap 属性

| Trap属性 | 描述 |
|---|---|
| Alarm or Event | Alarm |
| Trap Severity | Warning |
| Trap OID | 1.3.6.1.4.1.2011.5.25.42.3.1.4.2 |
| MIB | HUAWEI-L2VLAN-MIB |
| Alarm ID | 0x00F1FF0F/0xF1FF0F |
| Alarm Severity | Warning |
| Alarm Name | VCMP_MULTI_SERVER |
| Alarm Type | processingErrorAlarm |

| Trap属性 | 描述 |
|---|---|
| Raise or Clear | Raise |
| Match trap | VCMP_1.3.6.1.4.1.2011.5.25.42.3.1.4.10 hwVcmpServerMacConflictResume |

Trap Buffer 信息参数

| 参数名称 | 参数含义 |
|---|---|
| VcmpDeviceMac | 设备MAC地址 |

VB 信息参数

| VB OID | VB Name | VB Index |
|---|---|---|
| 1.3.6.1.4.1.2011.5.25.42.3. 1.5.1 | hwVcmpDeviceMac | - |

对系统的影响多台server配置都会被Client学习，业务不受影响。
可能原因同一个VCMP管理域中出现多个角色为Server的设备。
处理步骤
1. 在VCMP管理域中的每台设备上执行命令display vcmp status，通过字段Role，查看同一个VCMP管理域中是否存在多台角色为Server的设备。
● 只有一台角色为 Server 的设备，请执行步骤 3 。
● 存在多台角色为Server的设备，请执行步骤2。
2. 查看二层网络拓扑图，确定一台角色为Server的设备，在其他设备上执行命令vcmp role { client | silent | transparent }，确定设备的角色，查看告警是否恢复。
● 是，请执行步骤4。
● 否，请执行步骤3。
3. 请收集告警信息、日志和配置信息，并联系技术支持工程师。
4. 结束。
