Trap Buffer 信息解释Dual-active scenario is detected.

| Trap属性 | 描述 |
|---|---|

| Trap OID | 1.3.6.1.4.1.2011.5.25.246.1.1 |

| Alarm ID | 0x09A90000/0x9A90000 |

| Trap属性 | 描述 |
|---|---|
| Alarm Severity | Critical |
| Alarm Name | hwDadConflictDetect |
| Alarm Type | communicationsAlarm |
| Raise or Clear | Raise |
| Match trap | STACK_1.3.6.1.4.1.2011.5.25.246.1.2 hwDadConflictResume |

Trap Buffer 信息参数无VB 信息参数无对系统的影响网络上出现IP、MAC、全局配置完全一样的两台设备，即双主冲突，影响数据转发。
可能原因
● 原因1：
集群或堆叠线缆被拔出。
集群或堆叠管理链路的线缆被拔出。
● 原因2：集群或堆叠线缆故障。
处理步骤
● 原因1：
集群或堆叠线缆被拔出。
集群或堆叠管理链路的线缆被拔出。
1. 检查集群或堆叠线缆是否被拔出。
– 如果是，则请执行步骤2。
– 如果不是，则请执行步骤3。
2. 插入集群或堆叠线缆，恢复集群或堆叠连线。
3. 请收集告警信息、日志信息和配置信息，并联系技术支持人员。
● 原因2：集群或堆叠线缆故障。
1. 检查集群或堆叠物理成员端口指示灯是否正常。
– 如果是，则请执行步骤3。
– 如果不是，则请执行步骤2。

2. 请更换集群或堆叠线缆。
3. 请收集告警信息、日志信息和配置信息，并联系技术支持人员。
